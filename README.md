This repository contains various HTML tasks and mini projects that help in understanding:

- HTML Structure
- Headings and Paragraphs
- Lists
- Tables
- Forms
- Images
- Hyperlinks
- Semantic Tags
- Description Lists
- Timetables
- Resume Creation
- Basic Web Page Layouts

## 📂 Projects Included

- Student Resume

- Hyperlink Examples
- HTML Practice Programs
